Express app

api/index.ts
  • The only Vercel function: every URL is rewritten to it
  • Mounts /forecast /spots /live /summary
  • cacheFor() adds a Cache-Control header to each response
  • notFound and errorHandler run last
2

Route

src/routes/forecast.ts
  • findSpot("blouberg") loads the spot's config, or throws a 404
  • Calls forecastProvider, never Windguru directly
  • cacheUntilNextRun() keeps the response until the next model run
3

Provider adapter

src/providers/windguru/
a

Which run? latestRun() asks only when the schedule says one is due, then every 10 min until it lands

b

Fetch it once. storedRun() reads the run from the shared store, or fetches and stores it

c

Translate. map.ts turns Windguru's arrays into the shared format

Live wind takes the same path through macwind.ts: one GET, station times to UTC

4

HTTP client

src/lib/http.ts · fetchJson()
  • Shares one call between identical requests in flight
  • Retries network and 5xx errors once, 10 s timeout
  • Never retries 4xx (blocked or rate limited)
  • Pauses a failing URL 30 s, growing to 15 min
  • Circuit breaker: Windguru blocked → no calls for 1 h

Shared format

src/providers/types.ts
  • Responses: Forecast WaveForecast SpotInfo LiveReading Summary
  • Units: knots · degrees from · °C · metres · UTC
  • Contracts: ForecastProvider and LiveWindProvider; providers/index.ts picks which adapter implements them

Cache timing

api/index.ts · src/middleware/cache.ts
  • Forecasts: until the next run is due + 5 min (10 min to 6 h)
  • Summary: until the first spot's next run, built from the cached forecasts
  • Spot info: 12 h · Live: 60 s
  • Provider down: the CDN keeps the last good copy for 24 h (live 1 h)

Add a spot

One entry in spots.ts: Windguru id and grid points. Add it to the frontend's spots.ts too; its page is generated.

Switch provider

Write an adapter that implements the contract, add its ids in spots.ts, select it in providers/index.ts.

Terms: rundef

Names a model run: start date and hour, then the hours it covers. 2026100512x0x78x0x78

Terms: cachefix

The model grid point to read: lat x lon x altitude. Waves use a separate point out at sea.
