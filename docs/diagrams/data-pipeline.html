Fresh

The CDN answers from its cache. The backend and providers aren't called at all.

Stale while refreshing

Once fresh time is up, one visitor gets the old copy while the CDN fetches a new one. Usually 1–3 s.

Why "until the next run"

A run never changes once published, so the CDN only asks again when the next one is due, and the backend only checks Windguru then. The summary reuses those copies.

cacheFor() per route in api/index.ts; forecast and summary timing in secondsUntilNextRun().
